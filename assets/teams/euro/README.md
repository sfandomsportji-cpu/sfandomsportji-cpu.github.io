# National team crests

User-requested `euro` folder: eight national teams used by the 2026-11-13 previews. Images are stored locally, never hotlinked.
Source image bytes are preserved for PNGs; FIGC and AUF SVGs and the Argentina SVG are rasterized to transparent PNG without changing the artwork.
Artwork bounds are registered in src/content/logo_boxes.json so all eight follow the existing common logo size rules.

Sources: official England Football crest CDN (England, Czechia, Croatia, Spain); FFF website (France); FIGC website (Italy); AUF website (Uruguay). Argentina crest source: FootyLogos.com, https://www.footylogos.com/logos/argentina-national-team (source credit). Federation marks remain their respective owners' trademarks. See sources.json for exact URLs and hashes.
