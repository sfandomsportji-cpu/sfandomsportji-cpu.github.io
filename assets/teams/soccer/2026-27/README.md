# SFANDOM — European Big 5 football club crest archive (2026–27)

96 actual PNG images, stored in this repository (not external hotlinks). Structure:

- premier-league: 20 clubs
- la-liga: 20 clubs
- bundesliga: 18 clubs
- serie-a: 20 clubs
- ligue-1: 18 clubs

Images retained at their original resolutions. Each league folder contains a manifest.json mapping club names to image filenames; index.json maps all leagues.

Source collection: https://github.com/luukhopman/football-logos (2026–27 data). Source commit: 2a3978f0b4730645c205d855a4bda54c161183e9. Original repository paths and Git content SHA identifiers are recorded in manifests. Retrieved 2026-10-16.

## Korea / Japan club crests (added 2026-10-17)

SVG crests stored in this repository: k-league-1 (12), k-league-2 (17), j1-league (20), j2-league (20), j3-league (20). Each folder has an index.json with club names, slugs and original source URLs (FootyLogos, editorial/reference). Keys for src/content/soccer_logos.json are the upper-cased English club names, plus short keys used in article headers (e.g. SEOUL, ULSAN, SHIMIZU, FC TOKYO).
