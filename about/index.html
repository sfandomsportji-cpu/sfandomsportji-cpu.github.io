ABOUT. 소개

SFANDOM은 스포츠 분석가 Ji와 AI 분석 파트너 KAIRO가 함께 운영합니다. Ji의 분석 경험과 판단에 KAIRO의 데이터 정리·비교 분석·복기가 더해져, 경기 전후의 핵심 근거를 빠르고 이해하기 쉽게 전달합니다.

EARNED, NOT LUCK.

우리는 화려한 숫자보다 실제 경기 판단에 도움이 되는 숫자를 우선합니다.

분석은 복잡할 수 있지만 전달은 복잡할 필요가 없습니다. SFANDOM은 데이터의 깊이와 콘텐츠의 속도를 동시에 추구합니다.

경기 전에는 근거를, 경기 후에는 복기를 남깁니다.

SFANDOM은 불법 스포츠도박을 운영·중개·알선하지 않으며, 데이터 기반 분석과 건전한 스포츠 문화를 지향합니다.

SFANDOM이 지키는 기준.

DATA

감각보다 근거. 비교 가능한 지표와 현재 경기력을 중심으로 봅니다.

CLARITY

한눈에 이해되는 구조와 정보 위계를 중요하게 생각합니다.

ACCOUNTABILITY

결과뿐 아니라 판단 과정과 근거까지 복기하는 문화를 지향합니다.

사람의 판단과 AI의 정리를 분리합니다.

SFANDOM에서 Ji는 경기 맥락과 분석 방향, 최종 편집 판단을 담당합니다. KAIRO는 공개 자료를 구조화하고 비교 항목을 정리하며, 서로 다른 기록 사이의 일관성을 확인하는 분석 파트너 역할을 합니다.

AI가 수치를 정리했다는 이유만으로 내용을 자동 게시하지 않습니다. 선수 이름, 팀, 경기 날짜, 선발 정보와 핵심 기록은 가능한 범위에서 공식 자료와 다시 맞춥니다. 중요한 정보가 확인되지 않으면 빈칸을 추정으로 채우기보다 불확실성을 남깁니다.

이 구조의 목적은 사람의 직관을 AI가 대신하는 것이 아니라 반복적인 데이터 정리와 비교를 더 빠르게 만들어, 편집자가 실제 경기 맥락과 설명의 품질에 더 많은 시간을 쓰게 하는 데 있습니다.

무엇을 하고, 무엇을 하지 않는가.

ORIGINAL CONTEXT

공식 기록을 그대로 나열하는 데서 끝내지 않고 왜 그 장면과 수치가 중요했는지 자체 설명을 붙입니다. 경기 흐름, 선수 역할, 일정과 상대성을 연결해 독자가 기록의 의미를 이해할 수 있게 만드는 것이 콘텐츠의 핵심입니다.

SOURCE FIRST

공식 리그와 구단 기록을 우선하고 외부 기사나 데이터는 보조 자료로 사용합니다. 출처 링크가 있는 경우 원문을 직접 확인할 수 있게 연결하며, 출처 표시가 타인의 콘텐츠를 자유롭게 복제할 권리를 의미하지 않는다는 원칙을 지킵니다.

NO GAMBLING SERVICE

SFANDOM은 금전이 걸린 게임 운영, 가입 중개, 불법 스포츠도박 홍보나 수익 보장을 제공하지 않습니다. 경기 데이터는 스포츠 이해와 분석을 위한 정보로 다루며, 커뮤니티에서도 불법 사이트 유도와 금전 모집을 금지합니다.

외부 자료는 분석을 보조합니다.

선수 사진, 경기 기록, 기사와 공식 링크 등 제3자 자료가 필요한 경우 해당 자료는 원래 권리자의 권리를 존중하는 범위에서 사용합니다. 외부 자료 자체가 SFANDOM 콘텐츠의 목적이 되지 않도록 하고, 핵심 가치는 자체 해설과 데이터 해석에 둡니다.

직접 호스팅하거나 재편집할 권한이 불분명한 경기 영상은 사이트의 핵심 콘텐츠로 운영하지 않습니다. 공식 페이지로 연결할 수 있는 경우에는 원문 링크를 우선하고, 사이트 내부에서는 설명과 분석을 중심으로 구성합니다.

SFANDOM의 자체 문장, 편집 구조, 분석 프레임과 브랜드 디자인은 별도의 편집 콘텐츠입니다. 동시에 공개 경기 결과처럼 독점할 수 없는 사실과 제3자의 저작물은 구분해 다룹니다.

결과가 나온 뒤에도 기록을 남깁니다.

스포츠 분석은 결과를 알고 나면 누구나 그럴듯하게 설명하기 쉽습니다. 그래서 SFANDOM은 경기 전 판단과 경기 후 복기를 구분하고, 가능한 범위에서 당시 공개했던 분석을 기록으로 남기는 방식을 선호합니다.

기록보관소는 검색 노출을 늘리기 위한 페이지가 아니라 이전 콘텐츠를 다시 확인하기 위한 도구입니다. 최신 화면에는 현재 운영에 필요한 코드와 콘텐츠만 두고, 과거 콘텐츠는 별도 기록으로 분리합니다.

이 원칙은 사이트 운영에도 동일하게 적용됩니다. 테스트 코드, 폐기된 기능, 임시 UI를 숨겨 보존하지 않고 Git 이력에서 복원할 수 있도록 하여 공개 배포본을 단순하고 검증 가능한 상태로 유지합니다.

빠르게 올리는 것보다 확인 가능한 상태를 우선합니다.

스포츠 정보는 시간에 민감하지만 속도가 정확성을 대신할 수는 없습니다. SFANDOM은 새 정보가 들어왔을 때 기존 문장을 무조건 덧붙이기보다 현재 페이지의 역할과 사실관계를 다시 확인합니다. 선발이나 일정처럼 변경 가능성이 높은 정보는 확인 시점을 구분하고, 경기 종료 뒤에는 과거의 사전 분석과 결과 복기를 서로 다른 기록으로 다룹니다.

사이트 운영에서도 같은 원칙을 적용합니다. 테스트 기능이나 폐기된 코드를 화면 밖에 숨겨 두지 않고 현재 배포본에는 실제로 사용하는 기능만 남깁니다. 외부 모듈이 실패하더라도 본문과 핵심 콘텐츠가 계속 표시되도록 분리하고, 커뮤니티처럼 이용자 입력이 있는 기능은 운영 규칙에 따라 게시 후에도 검토·조치할 수 있도록 관리합니다.

독자가 SFANDOM에서 확인해야 하는 것은 화려한 시스템 설명이 아니라 실제 결과입니다. 출처를 확인할 수 있는 링크, 날짜가 분명한 콘텐츠, 정리된 기록, 수정 가능한 운영 구조를 통해 사이트의 신뢰도를 쌓는 것이 장기적인 목표입니다.
