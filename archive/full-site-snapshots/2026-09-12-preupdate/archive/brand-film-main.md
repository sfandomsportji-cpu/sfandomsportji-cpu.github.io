# SFANDOM Brand Film — Main Production Rule

Updated: 2026-09-04

## Monthly cadence
- Produce **one main brand-film advertisement per month**.
- Do not spend Runway credits during brainstorming or rough development.

## Pre-production rule
- Spend about **3 days** on script, synopsis, scene order, camera direction, subtitles, timing, and final review before using generation credits.
- Runway credits are used **only after the concept and production plan are locked**.
- Avoid unnecessary full re-generation; prefer controlled, minimal revisions.

## Credit discipline
- Treat each monthly credit allocation as a limited production budget.
- Drafts, experiments, and abandoned variants should not consume credits unless specifically approved for final production.
- Keep a reserve for essential fixes and final output.

## GitHub archive rule
- GitHub stores **only the approved MAIN version** of the monthly brand film record.
- Do not upload every draft, test render, prompt experiment, or intermediate revision.
- When the monthly main version changes, **update this MAIN record rather than creating clutter from multiple working versions**.
- Final published assets may be archived separately only when they are the approved release version.

## Working order
1. Script / synopsis development (~3 days)
2. Final scene and timing lock
3. Final review
4. Runway production
5. Minimal correction pass
6. Publish approved MAIN version
7. Update GitHub MAIN record only
