# SFANDOM 미국 스포츠 분석 콘텐츠 벤치마킹 보고서 v1.0

## 목적
미국의 대형 스포츠 분석·예측 개인 브랜드에서 검증된 강점을 추출해 SFANDOM 콘텐츠 제작 기준으로 재구성한다.
적용 대상: sfandom.com / NAVER Blog / Threads·Instagram / 향후 YouTube.

## 핵심 결론
미국에서 큰 팬층을 만든 스포츠 분석가들의 공통점은 단순히 예측을 잘하는 데 있지 않다.

**강한 제목 → 즉시 이해되는 핵심 주장 → 데이터 근거 → 자기만의 해석 → 반복 가능한 콘텐츠 시리즈 → 개인 브랜드**

SFANDOM 기본 조합:

> 이과장의 검색 유입력 + Warren Sharp의 데이터 스토리텔링 + Adam Levitan의 독자 친화적 장문 구성 + Ken Pomeroy의 데이터 신뢰도 + Cody Brown의 강한 후킹 + Phil Steele의 정보량 = SFANDOM식 스포츠 분석 콘텐츠

## SFANDOM이 가져올 10가지 장점

1. **제목에서 내용을 절반 설명한다.** 검색자가 무엇을 얻게 되는지 클릭 전에 보여준다.
2. **결론을 숨기지 않는다.** 결론 → 근거 → 반론 → 변수 → 최종 판단 순서로 쓴다.
3. **숫자의 의미를 설명한다.** 기록 나열보다 그 기록이 실제 경기에서 무엇을 바꾸는지 연결한다.
4. **독자적인 기준을 만든다.** SFANDOM POWER INDEX, FORM SCORE, MATCH PRESSURE INDEX, STARTER CONTROL SCORE, GAME FLOW RATING 등 자체 지표를 장기적으로 구축한다.
5. **긴 글도 쉽게 읽히게 만든다.** 짧은 문제 제기 → 사진 → 설명 → 데이터 → 사진 → 관찰 → 비교 → 결론 구조를 사용한다.
6. **분석가의 사람 냄새를 남긴다.** DATA SAYS / JI WATCHED / SFANDOM READ 세 층을 함께 둔다.
7. **하나의 사건을 여러 콘텐츠로 확장한다.** 경기 전 → 라인업 → 경기 중 → 경기 후 → 다음날 분석으로 이어간다.
8. **데이터를 시각적으로 보여준다.** 최근 10경기, 홈/원정, 좌/우완, 초반/후반 등 독자가 즉시 이해할 축으로 정리한다.
9. **개인 이름을 콘텐츠 브랜드로 만든다.** SFANDOM = 브랜드 / JI = 스포츠 애널리스트 / KAIRO = 데이터·콘텐츠 분석 파트너.
10. **소재가 달라도 같은 브랜드의 글처럼 느껴지게 한다.** 디자인보다 판단 방식 자체를 브랜드화한다.

## SFANDOM 최종 콘텐츠 공식

**HOOK** — 검색자가 궁금한 질문 또는 의외의 관찰

↓

**CLAIM** — SFANDOM의 핵심 판단

↓

**CONTEXT** — 경기·선수·시즌 상황

↓

**DATA** — 핵심 데이터

↓

**JI WATCH** — 실제 경기를 본 관찰

↓

**VISUAL** — 사진·그래프·비교표

↓

**COUNTERPOINT** — 반대 변수

↓

**SFANDOM READ** — 데이터 + 경기 흐름 종합 판단

↓

**NEXT** — 다음 경기에서 무엇을 볼 것인가

## 우선 벤치마킹 5인
- Warren Sharp — 데이터 스토리텔링

이 문서를 SFANDOM 콘텐츠 제작 기준서 v1.0의 뼈대로 사용한다.
