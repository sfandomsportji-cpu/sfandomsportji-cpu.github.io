# SFANDOM SITE INSPECTION #1

**Inspection ID:** SFANDOM-2026-08-31-01  
**Date:** 2026-08-31 KST  
**Type:** Full-site error inspection / analysis  
**Mode:** Diagnosis only — no runtime HTML/CSS/JS/content/deployment changes  
**Status:** Recorded

---

## 1. Summary

이번 점검은 SFANDOM 전체 사이트의 오류·불일치·외부 의존성 위험을 확인하기 위해 수행했다.

점검 중 사이트 코드 자체가 아닌 검사 도구 오류가 발생했으며, SFANDOM Operations Manual v2.2의 ERROR STOP & NORMALIZATION 원칙에 따라 즉시 중지 후 검사 경로를 정상화한 뒤 재개했다.

현재 확인 범위에서 사이트 전체 접속 불가나 메인 구조 붕괴에 해당하는 SEV-1/SEV-2 장애는 확인되지 않았다.

---

## 2. Findings

### F-01 · live-dock.js cache version mismatch
**Priority:** High  
**Classification:** Cache / deployment consistency

현재 `index.html`은 최신 `live-dock.js` 파일을 다음 버전 키로 참조한다.

`live-dock.js?v=20260827-clean5`

반면 관련 CSS는 더 최신 버전 키를 사용한다.

`live-dock.css?v=20260830-clean6`

실제 JS 파일 내용은 모바일 대응 수정본이지만 캐시 키가 오래되어 기존 방문자가 과거 JS를 재사용할 가능성이 있다.

**Action:** JS cache-busting version을 실제 최신 배포 상태와 맞춘다.

---

### F-02 · archive/picks archive.css cache version mismatch
**Priority:** Medium  
**Classification:** Cache / archive consistency

`archive/media/`는:

`archive.css?v=20260830-snapshot1`

을 사용하지만 `archive/picks/`는:

`archive.css?v=20260827-clean4`

를 사용한다.

동일 CSS 파일에 서로 다른 오래된 캐시 키가 남아 있어 페이지별 스타일 캐시 불일치 가능성이 있다.

**Action:** Archive 전체가 동일한 최신 cache-busting 기준을 사용하도록 대조한다.

---

### F-03 · Main / Content date synchronization mismatch
**Priority:** Medium  
**Classification:** Content synchronization

메인 홈은 2026-08-30 KST 콘텐츠를 표시하고 있으나 `content.html`의 DAILY CONTENT 날짜는 2026-08-24 KST 상태다.

기능 장애는 아니지만 정식 운영 시 사용자가 페이지별 최신성 차이를 인지할 수 있다.

**Action:** 메인 발행 루틴과 Content 페이지 갱신 정책을 분리할지 동기화할지 운영 기준을 확정한다.

---

### F-04 · 2026-08-31 morning content not yet on main
**Priority:** Operational status  
**Classification:** Publication state

2026-08-31 아침 콘텐츠는 준비되었으나 점검 시점 main에는 아직 반영되지 않았다.

이 항목은 코드 오류가 아니라 미발행 상태로 분류한다.

**Action:** 사이트 정상화 검증 완료 후 승인된 발행 절차를 재개한다.

---

### F-05 · LIVE server endpoint disabled / TEST MODE
**Priority:** Informational  
**Classification:** Module state

`live.html`의:

`<meta name="sfandom-chat-endpoint" content="" />`

값이 비어 있다.

따라서 LIVE는 서버 기반 실시간 채팅이 아니라 브라우저 테스트 모드로 동작한다.

현재 설계 의도에 따른 상태라면 오류가 아니다.

**Action:** 실제 공개 LIVE 전환 시 Worker/API endpoint 연결 여부를 별도 검증한다.

---

### F-06 · External image hotlink dependency
**Priority:** Medium / long-term  
**Classification:** External dependency

`content.html` 및 과거 PICK archive 일부 이미지가 MLB CDN 및 제3자 이미지 서버를 직접 참조한다.

외부 서버가 URL·referrer 정책·hotlink 정책을 변경하면 SFANDOM 코드 변경 없이 이미지가 깨질 수 있다.

**Action:** 신규 핵심 콘텐츠는 가능한 한 자체 `assets/`에 저장하고 외부 이미지 의존도를 점진적으로 줄인다.

---

### F-07 · Signature Moments depends on MLB Stats API
**Priority:** Low / monitored  
**Classification:** External API dependency

`signature-moments.js`는 MLB Stats API에서 경기·하이라이트 데이터를 조회해 영상 URL을 동적으로 해결한다.

API 응답 구조, 제목 문자열, CORS 또는 영상 URL이 바뀌면 개별 Moment 재생이 실패할 수 있다.

현재 JS에는 오류 발생 시 다음 Moment로 넘어가는 fail-safe가 있어 사이트 전체 장애로 확산될 가능성은 낮다.

**Action:** MODULE 성격으로 유지하고 본체와 결합하지 않는다.

## 4. Inspection-tool incidents

이번 점검 도중 사이트 오류와 구분해야 하는 검사 도구 오류가 발생했다.

1. URL 안전검사 경로 오류
2. Code Mode 최대 tool-call 제한

두 경우 모두 사이트 코드 오류로 단정하지 않고 즉시 STOP 후 검사 경로를 정상화했다.

이 기록은 향후 "검사 도구 오류"와 "SFANDOM 실제 오류"를 혼동하지 않기 위한 참고 기록이다.
