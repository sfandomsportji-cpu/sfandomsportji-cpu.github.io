# SFANDOM 공동회의용 — PR #30 검토·대책 통합 기록

**공유 주소:** https://github.com/sfandomsportji-cpu/sfandomsportji-cpu.github.io/pull/30  
**실행 구역:** feature/nba-injury-monitor-20261121 (초안 PR). **운영 main과 사이트에 적용 금지.**

## 공통 목표

축구·농구·야구의 라인업/부상/복귀 정보 정확성과 시간 신뢰성 확보.
스포츠 분석 및 픽은 운영자가 담당하고, 자동 장치는 정보의 출처·시각·상태를 감사한다.
기본값은 **비공개·미승인**. 빠른 속보보다 오보 방지가 우선.

## 공동 검토 분담표

| 담당 역할 | 검토할 항목 | 객관적 증거 |
|---|---|---|
| 데이터 검증 담당 | NBA 최신 PDF 레이아웃·상태의 실제 파싱 적합성; 출처 허가·갱신빈도 | 원문 URL, 보고서 발표시각, 선수별 비교표 |
| 시간 검증 담당 | ET DST, 유럽 경기 UTC→KST 자정 이월, MLB 더블헤더, 연말 일자 | 입력 ISO+IANA zone, 예상/실제 UTC·KST |
| 코드 검증 담당 | 데이터 오매칭, 일부 행 누락, 경고 전파, 파일 덮어쓰기 안전성 | 재현 입력, 로그, 실패 테스트 |
| 운영/장애 검증 담당 | 10분 예약 지연·누락; 공식 URL 2개 모두 실패; 캐시 장기 단절 | Actions run ID, 실행/발표시각, 사건 보고 |
| 화면/편집 검증 담당 | 색상 4종 의미, 확인시각·출처·정정 이력, 운영자 승인 동선 | 시안, 정상/실패/정보없음 화면 비교 |

역할은 특정 인물에게 지정한 것이 아니라 여러 검토 채널이 나눠 맡기 위한 영역이다.

## 위험 등급과 처리

- **P0:** 확정되지 않은 정보를 '출전 가능/예정/불가'로 오표시, 다른 선수/경기 잘못 매칭, 오래된 자료를 최신으로 위장, 비승인 자동 게시. **해결 전 병합·공개 금지.**
- **P1:** 10분 점검 누락, 잘못된 날짜 이월, 경고·복구 누락, 파서의 부분 수집. **검증 전 운영 전환 금지.**
- **P2:** UI 가독성, 용어 개선, 감사표 정렬 등. 핵심 안전장치 검증 이후 적용.

## 이번 공동 검토에서 발견한 실제 문제 및 대응

1. **복구 교착 버그(P1)** — 마지막 정상 수집 이후 22분을 넘으면 새로 성공한 수집도 실패 처리해 다음 기준 스냅샷으로 승격되지 못할 수 있었음.
   - 조치: 새 공식 보고서가 검증되면 감사 스냅샷의 신규 기준을 허용하고, 공백은 schedule_gap_alert=true / review_required=true 및 Actions 경고로 남김. **NOT_APPROVED는 유지.**
2. **NBA 보고서 시각의 DST 중복(P0)** — PDF 파일명은 ET 발표 시각만 포함하고 offset을 담지 않으므로 11월 01:xx 시각이 두 번 존재할 때 한 시각으로 추측하는 문제.
   - 조치: 중복 DST 시각/존재하지 않는 시각의 확정 변환을 거부하고 수동 확인 대기. 자동 KST 추정 금지.
3. **실제 NBA PDF 레이아웃 미검증(P0)** — 모의 PDF 행 단위테스트 통과만으로 실물 PDF의 모든 행/선수 매칭을 증명할 수 없음.
   - 조치 예정: 페이지별 행 수와 헤더/열 검증, 구단/선수/상태 원문 대비 수동 대조, 레이아웃 변경 시 전체 실패.
4. **기존 사이트 별도 빌드 검증 실패(P1)** — PR의 공통 시간 테스트와 무관하게 Verify generated site and game center에서 기존 분석 페이지 경로를 찾지 못해 실패.
   - 조치 예정: 기존 콘텐츠 회귀 여부를 별도 이슈로 조사. **자동 생성·사이트 배포는 이 PR에서 변경하지 않음.**
5. **실제 선발 라인업 공급원 미연결(P0)** — NBA injury report = 부상 분류일 뿐 starting lineup이 아님.
   - 조치 예정: 공식 선발 출처가 확보되기 전까지 lineup_source_verified=false; 선발 확정 표시 금지.

## 외부 검토자가 남길 형식

- **위험 등급:** P0 / P1 / P2
- **발견 경로:** 정확한 코드 파일/함수 또는 정보 출처 URL
- **재현 조건:** 경기 ID, 발표시각 원문, KST 변환 결과, 입력 예시
- **관찰 결과:** 현재 동작과 오류 화면/로그
- **기대 결과:** 무엇이 차단/표시/복구되어야 하는지
- **수정 제안:** 최소 변경 설계
- **검증 결과:** 테스트 명령 및 결과/실패 로그

## 통합 승인 조건

- 모든 P0 해결 + 실제 NBA 공식 PDF 최소 3개 발행 시점(선수·팀·상태 포함) 샘플 비교.
- P1 점검 간격, 시간 역전, ET DST, 유럽 자정 전후, MLB 더블헤더 재현 테스트.
- 공식 출처 이용 허가·수집 주기·배포 권리 검증.
- 사이트 표시/자동 게시 연결은 **별도 PR**, 운영자 명시적 승인 후만 진행.
- 10분 GitHub cron은 *최소 요청 주기*일 뿐 실행 지연/누락이 가능하므로 10분 SLA를 보장한다고 홍보하지 않음.
