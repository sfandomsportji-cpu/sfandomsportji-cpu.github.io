- 문서 유형: 자동 운영 지침 색인
- 적용 저장소: `sfandomsportji-cpu/sfandomsportji-cpu.github.io`
- 버전: 1.0
- 제정일: 2026-08-31
- 기준 시간대: Asia/Seoul (KST)
- 상위 원칙: 안정성 > 콘텐츠 정확성 > 속도 > 신규 기능
- 관련 문서: `docs/SFANDOM_SITE_OPERATIONS_MANUAL_v2.2.md`

## 1. 목적

이 문서는 SFANDOM 사이트의 매일 새벽 자동 점검·분석·안정화·코드 정비와 오전 결과 보고 절차를 고정한다. 자동 작업은 기존 사이트 구조와 정상 콘텐츠를 보호하면서 확인된 오류와 확실한 찌꺼기만 최소 범위에서 처리한다.

## 2. 고정 일정

| 시각(KST) | 작업 | 결과 |
|---|---|---|
| 매일 04:00 | 전체 점검 및 원인 분석 → 오류 안정화 → 안전 범위 찌꺼기 제거·코드 정비 → 변경 후 검증 | 작업 기록 생성 |
| 매일 09:00 | 당일 04:00 작업 결과 확인 및 한 장 요약 | 한국어 알림 보고 |

일정은 한국시간을 기준으로 하며, 날짜 계산에 UTC를 대신 사용하지 않는다.

## 3. 04:00 실행 순서

1. 작업 시작 시 현재 `main`과 라이브 사이트의 정상 기준점을 기록한다.
2. 사이트와 저장소 전체를 읽기 전용으로 우선 점검한다.
3. 발견 사항의 원인, 영향 범위, 심각도를 분석한다.
4. 오류가 하나라도 있으면 다른 정리 작업을 확대하지 않고 정상화를 우선한다.
5. 정상화 후에만 참조 관계가 명확한 찌꺼기와 중복 코드를 정비한다.
6. 변경 전후 검증을 모두 통과한 경우에만 결과를 유효한 정비로 기록한다.
7. 예상 밖 변화, 충돌, 권한 문제 또는 검증 실패 시 즉시 중단하고 안전한 이전 상태를 유지한다.
8. 변경·삭제·보류·검증 결과를 모두 로그에 남긴다.

## 4. 필수 점검 범위

- 라이브 사이트 접속, 주요 페이지와 내비게이션
- GitHub Pages 및 관련 워크플로 상태
- `index.html`, CSS, JavaScript, `data/`, `assets/`, `archive/`
- HTML/CSS/JS 문법 및 브라우저 콘솔 오류
- 깨진 내부·외부 링크, 이미지와 미디어 경로
- 중복 CSS/JS, 중복 이벤트 리스너, 미사용 import 및 고아 코드
- 임시 파일, 빌드 산출물, 숨은 잔여 데이터, 오래된 캐시 버전
- 데스크톱 1440px 및 모바일 390px 반응형 화면
- 가로 스크롤, 잘림, 레이아웃 이동, 메뉴·채팅·콘텐츠 영역 이상
- 변경 파일 외 예상하지 않은 diff

## 5. 오류 대응 원칙

- SEV-1/SEV-2 또는 사이트 핵심 기능 장애는 정리보다 복구를 우선한다.
- 오류 하나라도 확인되면 작업 범위를 넓히지 않는다.
- 원인을 확인할 수 없는 상태에서 추정 수정이나 연쇄 수정을 하지 않는다.
- 부분 수정은 최소 파일·최소 라인으로 제한하고 항상 되돌릴 수 있어야 한다.
- 검증 실패 시 추가 hotfix를 겹치지 말고 직전 정상 상태 복구를 우선 검토한다.
- 콘텐츠 발행, 전체 덮어쓰기, 구조 개편, 신규 기능 추가를 새벽 정비에 섞지 않는다.
- PR·병합·배포는 기존 SFANDOM 승인 및 검수 절차를 준수한다.

## 6. 찌꺼기 제거 기준

다음 조건을 모두 충족할 때만 삭제한다.

1. 저장소 전체 검색으로 참조 여부를 확인했다.
2. HTML/CSS/JS/Event Listener/Import/Asset 연결 관계를 확인했다.
3. 현재 페이지와 Archive 어느 곳에서도 사용하지 않는다.
4. 삭제 후 재검색 결과가 정상이다.
5. 콘솔 오류, 깨진 참조, 레이아웃 변화가 없다.
6. Git History에서 복구할 수 있다.
7. 삭제 근거와 대상을 작업 기록에 명시했다.

### 삭제 금지

- 용도나 참조 여부가 불확실한 파일·데이터·이미지
- Archive가 사용하는 콘텐츠와 자산
- 공식 로고, 캐릭터, 브랜드 원본
- 과거 기사·픽·분석 기록
- 정상 작동 중인 공통 코드와 CORE 구조
- 단순히 이름이 오래됐다는 이유만으로 판단한 파일

### 레거시 처리

- 불필요한 코드는 `display:none`, CSS override, 주석, 임시 비활성화로 숨겨 남기지 않는다.
- 제거가 확정된 기능은 관련 HTML/CSS/JS/Event Listener/Import/Asset 참조를 함께 제거한다.
- 과거 콘텐츠는 Archive에 보존하고, 과거 코드는 Git History에만 보존한다.
- 최신 배포본에는 검증되지 않은 숨은 레거시 코드를 남기지 않는다.

## 7. 변경 금지 및 보호 대상

- 기존 사이트 전체 덮어쓰기 금지
- 정상 구조·기능·레이아웃의 임의 변경 금지
- 확인되지 않은 파일·데이터·사진 생성 금지

- 콘텐츠 발행과 유지보수 작업의 혼합 금지
- 검증 없이 `main`에 직접 반영 금지
- 오류를 숨기기 위한 임시 패치 누적 금지
