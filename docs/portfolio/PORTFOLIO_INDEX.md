## Category key

- **Daily News** — 실제 메인에 발행된 주요 뉴스
- **Kairo Feature** — 카이로 특집 기사
- **Next Match** — 실제 메인 NEXT MATCH
- **Pick** — 실제 공개 Pick만 기록. 미발행은 `None`
- **Main Commit** — 해당 발행본을 main에 반영한 Git commit

## Rule
