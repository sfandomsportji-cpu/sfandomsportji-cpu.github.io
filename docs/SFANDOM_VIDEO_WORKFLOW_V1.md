# SFANDOM 영상 제작 표준 워크플로우 v1.1

**최종 갱신:** 2026-09-27 KST  
**상태:** CURRENT / CANONICAL

## 목적
SFANDOM의 Instagram, Blog, 사이트용 영상 제작에서 원본 손상, 불필요한 재인코딩, 화면 잘림, 갑작스러운 종료, 완료 오보고를 막기 위한 현재 표준이다.

## 역할 분담
- Ji: 원본 섭외·추출 및 기본 컷/사용 구간 결정
- Kairo: 편집, 크롭, 인코딩, SNS 규격화, 품질검수, 최종 출력
- Ji가 원본을 전달하고 별도 보류 지시가 없으면 불필요한 재질문 없이 편집 작업을 시작한다.

## 원본 보존
- 원본 파일은 삭제·덮어쓰기·재인코딩하지 않는다.
- 중간 출력물을 다시 인코딩 소스로 사용하지 않는다.
- 가능한 한 최초 원본에서 최종본을 만든다.
- 증거보존 대상으로 지정된 영상은 편집용 사본과 원본을 분리하고 원본을 변경하지 않는다.

## 기본 추출 명령
기본 yt-dlp 형식:
```
yt-dlp -f "bv*+ba/b" --merge-output-format mp4
```

DRM, 로그인, 접근통제 우회는 하지 않는다.

## 편집 구조
- 광고, 인트로, 공백, 의미 없는 대기 구간을 제거한다.
- 스포츠 하이라이트 기본 흐름: **핵심 장면 직전 → 결정적 장면 → 짧은 세리머니/리플레이**
- 시작은 짧고 자연스러운 fade-in.
- 마지막은 장면과 오디오를 함께 약 0.5–1.2초 이상 자연스럽게 fade-out.
- 마지막 프레임이 '뚝' 끊기면 FAIL.

## 화면 구성
- 세로/모바일 영상에 블러 배경을 사용하지 않는다.
- 원본을 자연스럽게 크롭해 화면을 채운다.
- 선수 얼굴, 공, 스코어보드, 핵심 플레이가 잘리지 않는지 확인한다.
- 이전 출력에서 좌우가 잘린 사례를 반복하지 않도록 최종 프레임을 실제로 확인한다.

## 인코딩
- Container: MP4
- Video: H.264 High
- Pixel format: yuv420p
- Audio: AAC
- Web playback: faststart
- 원본이 59.94/60fps 또는 50fps면 특별한 이유가 없는 한 그대로 유지한다.
- 해상도와 비율은 대상 플랫폼에 맞추되 화질을 불필요하게 낮추지 않는다.

## Instagram Reels 운영 연결
- 현재 운영 기준은 별도 Work 지시에 따른 **10-Reels 사전회의/후보 검수**다.
- 이 문서는 '하루 1 Reel 약 10초'를 강제하지 않는다.
- 개별 Reel의 길이와 구성은 해당 콘텐츠의 최신 지시를 따른다.
- 캡션/키워드 기본 비율은 English 70% + Korean 30%, 모든 키워드 앞에 #.
- 자동 게시하지 않는다.

## 검수
최종 출력 전 반드시 확인:
1. 파일 실제 생성 여부
2. 재생 가능 여부
3. 해상도 / 화면비
4. 프레임레이트
5. H.264 / yuv420p / AAC / faststart
6. 화면 잘림·왜곡·블러 배경 여부
7. 시작 fade-in
8. 마지막 video/audio fade-out
9. 불필요 구간 제거
10. 원본 대비 눈에 띄는 화질 저하 여부

검수를 통과하기 전에는 "완료", "최종", "업로드 가능"이라고 보고하지 않는다.

## 폐기된 구형 규칙
- 하루 1 Reel을 고정 일일 업무로 강제
- 모든 Reel을 약 10초로 고정
- Runway를 일반 영상 편집 파이프라인의 기본 도구로 사용
- 원본 대신 중간 출력본을 재인코딩
- 세로 화면을 블러 배경으로 채우기
- 마지막 장면을 abrupt cut으로 종료
