# Neurotechnology — Four-Tech Research Index

- **Index start (D-1):** 2026-08-31 (KST)
- **Purpose:** 공개 연구 및 기술 문헌을 기준으로 향후 검토·시연·증빙 정리에 사용할 4개 기술의 용어 색인.
- **Important scope note:** 아래 항목은 공개 연구 분야/전문용어를 정리한 것이며, 특정 정보기관·수사기관의 실제 보유·운용 사실을 이 문서 자체로 단정하지 않는다. 기관별 보유·사용 여부는 별도 증거와 공식 문서로 검증한다.

## 1. Brain Decoding — 브레인 디코딩
뇌에서 측정된 신경신호를 분석하여 발화, 움직임, 감각, 인지 상태 등 신경계가 표현하는 정보를 해석하거나 추정하는 기술 분야.

## 2. Semantic Decoding — 시맨틱 디코딩
뇌 활동 패턴으로부터 단순 신호를 넘어 단어, 개념, 문장의 의미 등 의미론적 정보를 추정·복원하는 기술 분야.

## 3. Visual Decoding / Visual Image Reconstruction — 시각 디코딩·시각정보 재구성
시각 관련 뇌 활동을 분석하여 사람이 보고 있거나 지각한 이미지의 특징·내용을 추정하거나 영상 형태로 재구성하는 연구 분야. 내부 대화에서 편의상 ‘Eyes Mirroring’이라고 부른 개념과 대응시키되, 공식 문서에는 전문용어를 우선 사용한다.

## 4. Auditory Decoding / Neural Speech Decoding — 청각·음성 디코딩
청각 및 음성과 관련된 신경 활동을 분석하여 들은 소리, 말소리 또는 발화 관련 정보를 해석·복원하는 기술 분야. ‘Sound Diffusion’은 음향학에서 별도 의미로 쓰일 수 있으므로 신경기술 문서에서는 Auditory Decoding / Neural Speech Decoding을 우선 표기한다.

### Evidence rule
향후 시연 또는 검증 시에는 입력 신호, 측정 장비, 실험 조건, 원시 데이터, 출력 결과, 시간 기록 및 재현 여부를 분리 보존하며, 공개 연구의 존재와 특정 기관의 실제 보유·사용 주장은 서로 분리하여 기록한다.
